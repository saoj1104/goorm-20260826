# 머니 문장 (Money Quote)

매일 한 편의 재테크 명언을 읽고, 쉬운 해설과 작은 실천으로 연결하는 모바일 우선 웹앱입니다.

> 명언 → 쉬운 해설 → 오늘의 실천 → 저장·공유

## 서비스 바로가기

[머니 문장 웹앱 열기](https://money-quote-daily.in-kwan.chatgpt.site)

현재 서비스는 소유자 전용 비공개 상태이므로 접속 시 로그인이 필요할 수 있습니다.

## 주요 기능

- 날짜를 기준으로 오늘의 명언 자동 표시
- 이전·다음 명언 탐색
- 명언별 쉬운 해설과 오늘의 실천 제공
- 카테고리별 명언 필터링
- 즐겨찾기 저장 및 해제
- 새로고침 후에도 즐겨찾기 유지
- 모바일 공유 기능과 클립보드 복사 대체 기능
- 모바일·태블릿·PC 반응형 디자인

## 디자인 특징

- 감성적인 전체 이미지 명언 카드
- 이미지 위 텍스트 가독성을 위한 어두운 그라데이션
- 큰 타이포그래피와 둥근 카드 UI
- 다크 테마와 라임 포인트 컬러
- 모바일 앱 형태의 고정 하단 내비게이션

## 기술 스택

- Next.js
- React
- TypeScript
- CSS / Tailwind CSS
- 브라우저 `localStorage`
- Web Share API 및 Clipboard API

서버나 데이터베이스 없이 브라우저에서 동작하는 MVP입니다.

## 로컬 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

개발 서버가 실행되면 터미널에 표시되는 로컬 주소로 접속합니다.

## 배포용 빌드

```bash
npm run build
```

## 프로젝트 구조

```text
goorm-20260826/
├─ app/
│  ├─ page.tsx       # 명언 데이터, 화면 및 기능
│  ├─ globals.css    # 카드 UI와 반응형 디자인
│  └─ layout.tsx     # 페이지 메타데이터
├─ public/           # 정적 파일
├─ package.json
└─ README.md
```

## 데이터 저장 방식

즐겨찾기는 사용자 브라우저의 `localStorage`에 저장됩니다.

```text
moneyQuote_favorites
```

계정이나 클라우드 동기화 기능은 아직 없으므로 다른 브라우저나 기기에는 공유되지 않습니다.

## 향후 개선 아이디어

- 명언 데이터 20~50개로 확장
- 검색과 세부 카테고리 추가
- 다크·라이트 테마 선택
- 최근 본 명언과 읽기 기록
- 명언 카드 이미지 저장
- AI 기반 맞춤 해설과 행동 추천

## 현재 MVP 범위

회원가입, 로그인, 결제, 데이터베이스, AI API와 클라우드 동기화는 포함하지 않습니다. 먼저 작고 안정적인 서비스를 완성한 후 단계적으로 확장하는 것을 목표로 합니다.
